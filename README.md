# Tic-Tac-Toe-by-using-HTML-CSS-JavaScript
🎮 Tic Tac Toe (Dynamic n × n Version)

Description:
A responsive and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.
This version lets players create a custom-sized board (n × n) — not just the classic 3×3 — and enjoy dynamic gameplay with color highlights, sound effects, and a running scoreboard.

🚀 Features

🧩 Dynamic board generation (3×3, 4×4, 5×5, or any size)

🎨 Modern UI with smooth colors and animations

🔁 Turn-based system for players X and O

🏆 Score tracking for both players

💡 Winning row/column/diagonal highlighted in green

🔊 Sound effects for moves, wins, and draws

⚡ Instant game reset option

📱 Responsive design — works on desktop and mobile

🧠 Tech Stack

HTML5 – structure

CSS3 – styling and animations

JavaScript (ES6) – game logic, DOM manipulation, and interactivity
